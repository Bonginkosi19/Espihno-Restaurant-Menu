# 🍝 Espinho Restaurant & Bar - Digital Menu

Modern, responsive digital menu for Espinho Restaurant & Bar in Siteki, Eswatini.

## 🌟 Features

- **Interactive Menu Categories**: Seafood, Pasta, Meat, Wines, Cocktails, Whiskey
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Modern UI**: Black & gold theme matching Espinho's premium brand
- **Smooth Navigation**: Sticky header with category tabs
- **Contact Information**: Direct links to call, email, and Instagram

## 🚀 Live Demo

[View Live Menu](https://bonginkosi19.github.io/Espihno-Restaurant-Menu/)

## 🛠️ Technologies Used

- React 18
- Tailwind CSS
- Lucide React (Icons)
- GitHub Pages / Netlify

## 📦 Installation
```bash
# Clone the repository
git clone https://github.com/bonginkosi19/Espihno-Restaurant-Menu.git

# Navigate to project directory
cd Espihno-Restaurant-Menu

# Install dependencies
npm install

# Start development server
npm start
```

## 🏗️ Build for Production
```bash
npm run build
```
